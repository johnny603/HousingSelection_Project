# SFSU CSC 101 - Project 1: Developers as Decision Makers

In our first project, we are going to use all of what we have learned so far to make a Java program for deciding who gets Housing at SFSU. The program will use a set of factors to help determine if a particular student would be allocated on-campus housing. In addition, we will need to ask students a few questions to determine their availability. Based on their responses and our set of factors, we can assign a score to each student to determine their eligibility for housing. While completing this project, you will also be asked to reflect on the current algorithms used, as well as reflect on the algorithm you have developed.
Language: Java
IDE: IntelliJ
